C'est quoi une habilitation ?

Une habilitation dans Chronotime est un droit d'accès ou une permission accordée à un utilisateur ou à un profil pour effectuer des actions spécifiques dans le logiciel.

Voici les points clés à retenir :

  • Structure : Les habilitations sont regroupées par profils.
  • Niveaux : Elles déterminent ce qu'un utilisateur peut voir (Lecture) ou modifier (Écriture).
  • Héritage : Un utilisateur peut hériter des droits de son groupe de fonctionnalités.
